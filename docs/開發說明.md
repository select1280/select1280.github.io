# 開發說明

本版包含漂流瓶、航誌、4 款遊戲與 8 款工具。

## 新增內容

- `developer-tools.js`：JSON 格式化與壓縮、Unix 時間戳雙向轉換、逐行差異比較。
- `journal.js`：每日漂流瓶（台北日期，6 則輪換）、本機收藏。
- `journal.html`：網站實作航行日誌與收藏內容。
- `content.css`：新內容樣式，已合併至目前使用的 `site.css`。
- `layout.json`：共用導覽與頁尾。修改後執行 `node build-layout.cjs` 同步五頁。

## Commit 慣例

之後的 commit 使用中文摘要，例如：

- `新增：每日漂流瓶與本機收藏`
- `新增：JSON、時間戳與文字差異工具`
- `整理：共用導覽與航行日誌`

不改寫已發布的歷史 commit。

## 回訪與停留的下一步

1. 每日挑戰：每天固定題目，可分享不含個資的成績文字。先做本機成績，不冒充全球排行榜。
2. 深海收藏：收藏漂流瓶與彩蛋徽章，附可見的進度，不強迫每天簽到。
3. 每週新增一篇短日誌：記錄真實問題與取捨，提供近期更新入口。
4. 工具深連結：讓每個工具有可分享的獨立網址，搭配範例輸入與操作教學。
5. 真實統計：待選定分析服務後，再比較每日活躍、回訪比例、工具完成率與分享入口帶來的訪問；目前無法從 localStorage 得知全站回訪率。

先觀察訪客真正使用的功能，再決定增加什麼。不可使用假人數、假倒數或沒有依據的成長百分比。

## 目前限制

JSON 使用 JavaScript 標準解析器，大整數可能失去精度。差異工具最多各 300 行、30,000 字元。輸入資料不上傳；漂流瓶收藏保存在此瀏覽器，跨裝置不會同步。漂流瓶內容目前為 6 則循環，並非無限每日新內容。
