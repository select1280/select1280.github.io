# 首頁天氣資訊列

- 來源：Open-Meteo Forecast API（https://open-meteo.com/en/docs）。使用 current temperature_2m、weather_code、is_day，攝氏與 Unix 時間戳。
- 僅首頁載入；城市中心座標，不要求裝置定位。支援台北、新北、基隆、桃園、新竹、台中、台南、高雄、花蓮、台東。
- 30 分鐘本機快取；切換城市取消舊請求；8 秒逾時。失敗時提供重試，可回退至 24 小時內且明確標示的舊資料。
- 顯示 API 的資料時間，不把本機請求時間當資料更新時間。資料來自氣象模式，並非附近測站的即時觀測。
- 畫面保留來源連結；目前採非商業免費端點，不含私密金鑰。若用途轉為商業，重新確認方案與授權。
- 測試覆蓋 WMO 代碼、日夜、無效資料、單位、快取邊界、過期時間與錯誤回應。正式 API 連線與手機畫面需在發布後驗證。
