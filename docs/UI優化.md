# UI 與操作流程優化

- 首頁順序：海洋場景 → 精選功能 → 漂流瓶與航誌入口。
- 深度概念圖移到關於頁，避免首頁多個區塊同時搶主題。
- `src/shared/catalog.js` 統一十二個功能的名稱與分類文字，首頁和目錄共用。
- 移除沒有期限的 NEW 標籤；裝飾圖像不再重複給螢幕閱讀器朗讀。
- JSON、文字比較、文字整理、URL、UUID、時間戳使用加寬工作視窗。
- 工具開啟後聚焦第一個輸入；Esc／關閉後返回原卡片；背景頁面鎖定捲動。
- 彈窗關閉鈕保持在頂端。手機輸入字級至少 16px，複雜輸入區採單欄。
- 加入跳至主要內容、可見焦點與篩選按鈕狀態。
- 深色文字提高閱讀清晰度，減少不必要的區塊進場隱藏。

驗證：功能測試、建置、所有站內連結與錨點、重複 ID 檢查已通過。本機預覽網路受限，尚待正式站的桌面及手機畫面、鍵盤閉環與工具輸入驗證。

`src/styles/refinement.css` 收錄本輪視覺調整，由建置時接到主樣式後。後續仍可將相同規則逐步收斂到主樣式，避免影響既有遊戲。
